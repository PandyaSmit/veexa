FEATURES

Everything you reach for daily. Nothing you don’t.

Postgres & MySQL, one app

Native drivers for both, SSH tunneling with password or private key, and credentials stored in your OS keychain.

A real SQL editor

Monaco-powered, with schema-aware autocomplete, multi-statement runs that each get a result tab, and one-click cancel.

Edit rows, review, commit

Double-click a cell to edit, add or delete rows, then preview the generated SQL and commit it in a single transaction.

Safe by default

Per-connection read-only mode, confirmation before DROP, TRUNCATE, DELETE or UPDATE, and server-side query timeouts.

Follow foreign keys

Click an FK cell to open the referenced row in a new tab. Inspect columns, types, defaults, keys and indexes in the structure view.

A workspace that remembers

Tabs persist across restarts. Pin tables, save queries per connection, and dig through your last 500 runs. CSV import and export built in.

KEYBOARD FIRST
